CONTROL STACKUP

AIRBRAKES & CANARDS ROCKET CONTROL TO 30,000 FT

Project Portfolio

Guidance, Navigation, and Control

This project's GNC codebase builds upon the previous iteration. Canards roll control is implemented using a PID controller. Airbrakes uses a Model Predictive Controller. Aerodynamic surfaces are modelled with ANSYS, and control schemes are tuned with RocketPy. A Monte Carlo method chooses the optimal control parameters. For more detail, check out 2024-2025 canards write-up.
